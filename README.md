# המקרר המשותף

אפליקציית ווב (PWA) לטאבלט משותף: כל אחד בוחר את השם שלו, מוסיף מאכלים עם תאריך תפוגה, מוחק מה שנגמר, ורואה בתצוגת "כל המקרר" את המאכלים של כולם מהתוקף הישן לחדש. כשמאכל פג תוקף האפליקציה מציגה באנר אדום בראש המסך ומספר אדום על הלשונית "כל המקרר". אין התרעות מערכת למכשיר.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה (עיצוב + לוגיקה) |
| `manifest.json` | מאפשר "הוספה למסך הבית" עם שם ואייקון |
| `sw.js` | עבודה בלי אינטרנט |
| `icon-192.png`, `icon-512.png` | אייקונים |
| `serve.ps1` | שרת קטן לבדיקה ברשת הביתית |

הנתונים נשמרים בזיכרון הדפדפן של הטאבלט עצמו (localStorage). אין שרת ואין חשבונות.

## איך להעביר לטאבלט

**אפשרות א׳ (מומלץ): אחסון חינמי ב-GitHub Pages**
1. פותחים מאגר חדש ב-GitHub ומעלים אליו את כל הקבצים בתיקייה הזו.
2. ב-Settings → Pages בוחרים Branch: `main`, תיקייה `/ (root)` ושומרים.
3. אחרי דקה מקבלים כתובת `https://<שם>.github.io/<מאגר>/`. פותחים אותה בכרום בטאבלט.
4. בתפריט הדפדפן בוחרים **"הוספה למסך הבית" / "התקנת אפליקציה"**. האפליקציה תיפתח במסך מלא כמו אפליקציה רגילה.

כתובת `https` נדרשת כדי שההתקנה על מסך הבית תעבוד. זו הסיבה שזו הדרך המומלצת.

**אפשרות ב׳: ברשת הביתית בלבד (לבדיקה)**
```bash
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
הסקריפט מדפיס כתובת כמו `http://192.168.1.20:8080/`. פותחים אותה בטאבלט כשהמחשב דלוק.

## איך סימון פגי התוקף עובד

- בכל דקה, ובכל פעם שהאפליקציה חוזרת לחזית, נבדק מה פג תוקף.
- מאכל שתאריך התפוגה שלו עבר מסומן באדום, מופיע בבאנר אדום בראש המסך ונספר במספר האדום על הלשונית "כל המקרר".
- מאכל שפג היום מסומן בכתום ("פג תוקף היום"), ומאכל שפג בתוך יומיים מסומן "פג בקרוב".

## פריטי דוגמה

בפעם הראשונה מופיעים ארבעה פריטי דוגמה (מסומנים "דוגמה") כדי לראות איך זה נראה. כפתור **"הסר את פריטי הדוגמה"** בתחתית המסך מנקה אותם.
